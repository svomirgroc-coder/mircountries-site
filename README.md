# mircountries.com

Сайт MirCountries: достопримечательности мира на 3D-глобусе.

- `index.html` — главная (глобус, список объектов, блок «MirCountries Publisher»).
- `objects.js` — данные объектов (обновляется из таблицы / n8n).
- `privacy-policy/`, `terms-of-service/` — юридические страницы.
- `assets/` — библиотека globe.gl и текстуры Земли.

Публикуется автоматически через Cloudflare Pages при каждом изменении ветки `main`.
